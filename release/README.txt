Trousse | Outfit composer for Skyrim Special Edition and Anniversary Edition

Requirements
64-bit Windows, a Skyrim SE or AE installation managed by Vortex, and
BodySlide and Outfit Studio 6.1.0 or later. Deploy your BodySlide mod and
the outfit mods you want to use before scanning the library.

Portable ZIP (Windows-x64)
1. Extract the ZIP to a folder where Trousse can stay and run Trousse.exe.
2. In Settings, select the Vortex Mod Staging Folder and the BodySlide
   folder that contains OutfitStudio.exe. Select Scan library.
3. To launch it from Vortex, select Skyrim Special Edition, open Tools,
   click +, set the name to Trousse, choose Trousse.exe as the target,
   and save. Older Vortex layouts may show Tools on the Dashboard.

Vortex extension ZIP
1. In Vortex open Home > Extensions and drop the intact
   Trousse-<version>-Vortex-Extension.zip onto Drop File(s). Restart
   Vortex when prompted. The Skyrim Mods page installs outfit packages.
2. Open Skyrim Special Edition > Tools > Trousse, and click Play on its row.
   The extension passes the game's path and current staging folder to
   Trousse. Select the Skyrim installation in Vortex if it is listed as
   missing after connecting an external drive.
3. To uninstall, remove the extension in Extensions and remove the Trousse
   shortcut from Tools if it is still listed.

Use Installed outfit to check a deployed mesh. Filter by sex, equipment
category, and first- or third-person view. Copy console command prepares
player.additem for the selected item. Enable the racial view when Unique
Bodies by Race is available. Refresh after deploy or a build in BodySlide.
Builds from the BodySlide log and possible matches by geometry are shown
separately. Trousse also identifies the verified Vortex deploy source.
Use Guide in Trousse for composition and export. Install only the resulting
outfit ZIPs from the Skyrim Mods page. Source outfits, presets and game
files need to be installed separately. Open KID after adding an outfit to
the package. Enable a custom rule and select the parts the character
should cover with an animation. For upper-body-only modesty, check Cover
upper body and clear Cover lower body. The outfit ZIP includes the INI
for all-race rules and the OAR patch for race-specific rules. Save KID
also exports the all-race rules as a separate INI.

In Compose, Variants and records lists console IDs, texture sets and
items sharing an Armor Addon. To replace a specific color, select its
linked records and choose Replace selected variants. Enable the generated
Variants ESP in Vortex, deploy and build the new BodySlide project.
Resolve Armor Addon conflicts in Vortex if another plugin edits the same
records. Custom racial Armor Addons can still point to their own meshes.

Bodies builds both weights of the selected CBBE project and preset in the
background. Trousse reuses the cached previews after a restart. In OAR,
select an animation mod and a race to control
activation for that race. The general INI applies to all races. Export mod
patch writes the changed OAR user.json files to a Vortex ZIP. Deploy the
patch after its source mods.

Poses reads installed PoserData packs. Add poses to Favorites, then save
Favorites.json. Trousse proposes the Poser Hotkeys Plus Vortex folder
when detected. You can choose another PoserData folder. Redeploy Vortex
after saving into its staging folder.

Select a pose and choose 3D preview to view a compatible human HKX in
Trousse with the body, preset and weight from Bodies. In 3D mode the
model updates as you select poses. Longer clips offer a timeline and
playback. Gallery shows images installed with the pose pack. If Trousse
offers Open in BodySlide for a file, choose Animation > Load HKX in the
BodySlide preview and paste the copied path.

In Package, use Save outfit report to export an ODT with the Skyrim items,
source mods and pieces. The outfit ZIP also contains the report. Vortex
reads requirements with a Nexus ID when it installs the outfit ZIP. Check
required_mods.txt for external sources that require manual verification.

Dress Up Lovers lets you create named outfits from game equipment, or
send a BodySlide piece or a game item from Compose with Use in Dress Up.
For a mesh replacer, use the game item that receives the replacement.
Choose Save to Skyrim or copy the exported CustomOutfit_ProfileN.json
to Data\SKSE\Plugins\DressUpLovers\User. In the Dress Up Lovers MCM,
open Backup Custom Outfits, select the same profile and use Import profile.
Import replaces the current custom outfits. Back up the current profile
in the MCM first if you want to edit or preserve those outfits. The game
editor can remove weapons when rebuilding an outfit.

Italiano

Requisiti
Windows a 64 bit, Skyrim SE o AE gestito da Vortex e BodySlide and Outfit
Studio 6.1.0 o successivo. Fai il deploy di BodySlide e delle mod degli
outfit prima di scansionare la libreria.

ZIP portatile (Windows-x64)
1. Estrai lo ZIP in una cartella stabile e avvia Trousse.exe.
2. In Impostazioni seleziona la cartella staging di Vortex e la cartella
   BodySlide che contiene OutfitStudio.exe. Avvia la scansione.
3. Per avviare Trousse da Vortex, seleziona Skyrim Special Edition, apri
   Tools, premi +, assegna il nome Trousse, scegli Trousse.exe come
   eseguibile e salva. Nelle versioni precedenti Tools può essere nella dashboard.

ZIP dell'estensione Vortex
1. Apri Home > Extensions in Vortex e trascina lo ZIP intero
   Trousse-<versione>-Vortex-Extension.zip su Drop File(s).
   Riavvia Vortex quando richiesto. La pagina Mods di Skyrim installa
   i pacchetti degli outfit.
2. Apri Skyrim Special Edition > Tools > Trousse e avvialo dalla sua riga.
   L'estensione passa a Trousse i percorsi del gioco e della cartella
   staging. Se dopo aver collegato un disco esterno Vortex indica che il
   gioco è assente, riseleziona il percorso di Skyrim in Vortex.
3. Per disinstallare, rimuovi l'estensione da Extensions e rimuovi il
   collegamento Trousse da Tools se è ancora presente.

Apri Outfit installato per controllare una mesh distribuita. Puoi filtrare
per sesso, categoria e vista in prima o terza persona. Copia comando console
prepara player.additem per il capo scelto. Attiva la vista per razza se usi Unique
Bodies by Race. Usa Aggiorna dopo il deploy o una build in BodySlide.
Le build del log di BodySlide sono distinte dai progetti compatibili per
geometria. Trousse indica anche la sorgente del deploy quando la verifica.
In Trousse, apri Guida per la composizione e l'esportazione. Nella pagina
Mods di Skyrim si installano gli ZIP degli outfit generati. Le mod sorgenti,
i preset e i file del gioco si installano a parte. Apri KID dopo aver
aggiunto l'outfit al pacchetto. Attiva la regola personalizzata e spunta
le parti che il personaggio deve coprire con l'animazione. Per coprire
solo sopra, spunta Copri sopra e lascia Copri sotto deselezionato. Lo ZIP
include l'INI per tutte le razze e una patch OAR per le regole per razza.
Salva KID esporta le regole per tutte le razze anche come INI separato.

In Componi, Varianti e record mostra gli ID console, i set di texture e i
capi che condividono un Armor Addon. Per sostituire un colore, seleziona
i record collegati e scegli Sostituisci varianti selezionate. Attiva l'ESP
Variants in Vortex, fai il deploy e costruisci il progetto in BodySlide.
Se più plugin modificano gli stessi Armor Addon, gestisci il conflitto in
Vortex. Gli Armor Addon razziali possono puntare ancora alle proprie mesh.

Corpi costruisce in background entrambi i pesi del progetto CBBE con il
preset selezionato. Trousse riusa le anteprime salvate anche dopo il
riavvio. In OAR, scegli una mod e una razza per
regolarne l'attivazione per quella razza. L'INI generale vale per tutte le
razze. Esporta patch mod scrive i file user.json in uno ZIP. Fai il deploy
dopo le mod sorgenti.

Pose legge i pacchetti PoserData installati. Aggiungi pose ai preferiti e
salva Favorites.json. Trousse propone la cartella Vortex di Poser Hotkeys
Plus quando la rileva. Puoi scegliere un'altra cartella PoserData. Ripeti
il deploy in Vortex dopo aver salvato nello staging.

Seleziona una posa e scegli Anteprima 3D per visualizzare un HKX umano
compatibile in Trousse con corpo, preset e peso scelti in Corpi. In modalità
3D il modello si aggiorna quando cambi posa. I clip più lunghi hanno una
barra temporale e il pulsante Riproduci. Galleria mostra le immagini
installate con il pacchetto. Se Trousse propone Apri in BodySlide, scegli
Animation > Load HKX nell'anteprima di BodySlide e incolla il percorso.

In Pacchetto, Salva riepilogo ODT esporta un documento con i capi Skyrim,
le mod sorgenti e i pezzi. Il documento è anche nello ZIP dell'outfit.
Vortex legge le dipendenze con ID Nexus quando installa lo ZIP.
Consulta required_mods.txt per le sorgenti da verificare a mano.

Quando la generazione individua un conflitto, Componi apre l'outfit
coinvolto e mostra in rosso i pezzi, il nome o la destinazione
individuati. In Pacchetto sono evidenziati gli outfit coinvolti.

In Dress Up Lovers puoi creare outfit col nome da mostrare in gioco
e aggiungere capi dalla lista o da Componi con Usa in Dress Up. Per un
mashup che sostituisce una mesh, aggiungi il capo di destinazione.
Usa Salva in Skyrim oppure copia il JSON CustomOutfit_ProfileN.json
in Data\SKSE\Plugins\DressUpLovers\User. Nel MCM di Dress Up Lovers
apri Backup Custom Outfits, seleziona lo stesso slot e scegli Import profile.
L'importazione sostituisce gli outfit correnti. Per modificare o conservare
quelli già presenti in gioco, esportali prima dal MCM. L'editor in gioco
può rimuovere le armi quando ricostruisce l'outfit.
